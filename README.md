# Altrix — AI-Powered Personal Health Copilot (Front-End Demo)

A responsive HTML/CSS/JavaScript prototype for a personal health copilot dashboard.

## Run it
1. Download and extract the ZIP.
2. Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.
3. Explore the clickable body-map points, timeline, report modal, and demo assistant.

## Files
- `index.html` — page structure
- `style.css` — dark glassmorphism styling, responsive layout, animation
- `script.js` — modal interactions, sample body-map details, demo chat responses

## Included UI interactions
- Interactive heart/lung hotspots
- Sample health metrics and timeline
- Report-picker demo (files stay local; no upload occurs)
- Demo health assistant with predefined responses
- Responsive mobile layout and toast messages

## Important
This is a front-end prototype. It does not connect to an AI model, store medical records, upload files, or provide diagnosis. All shown health data is fictional sample data. Do not use it for medical decisions. A production version would require secure backend infrastructure, privacy controls, validated clinical content, and qualified medical oversight.
